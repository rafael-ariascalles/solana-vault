How the vault program fits together

A Solana program has no main(). It is a library on-chain: a client builds a transaction naming the program, one instruction, and a list of accounts; the runtime calls the generated entrypoint, and Anchor's macros turn that into argument decoding, account validation, and a call into your handler.
